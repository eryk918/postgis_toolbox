about=Everyday PostGIS chores from inside QGIS.
 - Manage databases: connections, databases, schemas, PostGIS check, sessions and locks, pick the active database.
 - Import vectors and rasters from the project or from files, several at once (rasters are tiled and compressed, with overviews if you want).
 - Table registry: all tables, views and rasters of the active database with their geometry, SRID, resolution, size, owner, comments, privileges, columns, keys, indexes and overviews; add to project or drag onto the map, export, rename, move, copy, drop, vacuum, index, fix SRID or geometry type, rebuild overviews, grant privileges (per table or per schema), edit comments, copy the CREATE statement, manage QGIS styles saved in the database, copy tables to another database, run a database health check with one-click fixes.
 - Projects in database: open, save and delete QGIS projects stored in the active database.
 - Query editor: DB Manager SQL window with schema-qualified tables, PostGIS function help, create table / view from a query.
 - 24 Processing algorithms (buffer, clip, intersection, difference, merge, aggregate, dissolve, repair, simplify, centroids, cluster, Voronoi, nearest neighbour, point and polygon generation, raster clip, merge, reproject, resample, summary, tiling, slope / aspect / hillshade, raster to polygons, zonal statistics) that run in the database.
 Needs PostgreSQL with PostGIS (postgis_raster for the raster tools). English and Polish.

 - raster import: several files at once, compressed tiles, batched inserts, tile size presets
 - layer styles, schema-wide privileges and copying to another database in the registry, sessions and locks in the database manager
 - QGIS projects stored in the database: open, save, delete
 - 8 new Processing algorithms: cluster, simplify, Voronoi, centroids, dissolve, terrain analysis, raster to polygons, zonal statistics

 - redesigned dialogs with native QGIS widgets, dark theme support

 - new scalable icons
