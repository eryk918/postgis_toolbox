about=Everyday PostGIS chores from inside QGIS.
 - Manage databases: connections, databases, schemas, PostGIS check, pick the active database.
 - Import vectors and rasters from the project or from files (rasters are tiled, with overviews if you want).
 - Table registry: all tables, views and rasters of the active database with their geometry, SRID, size, owner, privileges, columns, keys, indexes and overviews; add to project or drag onto the map, export, rename, move, copy, drop, vacuum, index, fix SRID or geometry type, rebuild overviews, grant privileges.
 - Query editor: DB Manager SQL window with schema-qualified tables, PostGIS function help, create table / view from a query.
 - 16 Processing algorithms (buffer, clip, intersection, difference, merge, aggregate, repair, nearest neighbour, point and polygon generation, raster clip, merge, reproject, resample, summary, tiling) that run in the database.
 Needs PostgreSQL with PostGIS (postgis_raster for the raster tools). English and Polish.
