about=The everyday PostGIS stuff without leaving QGIS.
 - Databases: pick a connection, see what's on the server, add / rename / drop databases and schemas, check PostGIS, see who's connected and kill a stuck session, choose the database the rest of the plugin works on.
 - Import: vectors and rasters from the project or from disk, many at once. Rasters get tiled, compressed and get overviews if you want.
 - Table registry: one list of every table, view and raster in the database, with geometry, SRID, resolution, size, owner, comments, privileges, columns, keys, indexes and overviews. Add to the project or drag onto the map, export, rename, move, copy (also to another database), drop, vacuum, index, fix SRID or geometry type, rebuild overviews, set privileges per table or per schema, edit comments, grab the CREATE statement, manage styles saved in the database. A health check finds tables without a key or index, bloated tables, unused indexes and rasters without constraints, and fixes them with one click.
 - Projects in the database: open, save and delete QGIS projects kept in the database, same storage as QGIS itself.
 - Query editor: the DB Manager SQL window with schema-qualified tables, PostGIS function help and create table / view from a query.
 - 24 Processing algorithms running in the database: buffer, clip, intersection, difference, merge, aggregate, dissolve, repair, simplify, centroids, cluster, Voronoi, nearest neighbour, point and polygon generation, raster clip, merge, reproject, resample, summary, tiling, slope / aspect / hillshade, raster to polygons, zonal statistics.
 Needs PostgreSQL with PostGIS (postgis_raster for the raster tools).
