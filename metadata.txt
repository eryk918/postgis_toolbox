about=The everyday PostGIS stuff without leaving QGIS.
 - Databases: connect (pg_service.conf included), browse the server, add / rename / drop databases and schemas, check PostGIS, watch and kill sessions.
 - Import: vectors and rasters from the project or from disk, many at once, rasters tiled and compressed with overviews.
 - Table registry: every table, view and raster in one list, filtered by type, with all the details. Load, export, rename, move, copy, drop, vacuum, index, fix SRID or geometry type, set privileges, manage styles. A health check finds problems and fixes them with one click.
 - Projects in the database: open, save and delete QGIS projects stored in PostgreSQL.
 - Query editor: the DB Manager SQL window with PostGIS function help, create table / view from a query and one-click EXPLAIN ANALYZE.
 - 24 Processing algorithms running in the database, vector and raster, from buffer and clip to terrain analysis and zonal statistics.
 Needs PostgreSQL with PostGIS (postgis_raster for the raster tools).

changelog=2.1
 - runs on QGIS 4 (Qt6), same code still works on QGIS 3.34.9 and newer
 - every Processing algorithm has a description in the help panel, a tooltip and a Help button opening the PostGIS docs
 - vector algorithms: "Selected features only" option
 - every SQL statement an algorithm runs is written to its log
 - clip: choose the spatial relation, lines crossing a polygon are no longer skipped, touching polygons no longer break it
 - nearest neighbour: number of neighbours, distance and neighbour id columns, maximum distance 0 means no limit
 - intersection: optional transform of the mask layer to the input layer CRS
 - generate points: every point as a separate feature, polygon layers only
 - no more upper limits on buffer size, distances, point count and raster resolution
 - Ctrl+click on "Manage databases" connects straight to the last used database
 - table registry: index size column
 - query editor: "Explain analyze" button
 - table registry: type filter (vector, raster, tables, views)
 - pg_service.conf connections fully supported, password asked once per server
 2.0.1
 - fix password prompt for every database on the server
 - keep import dialogs open and on top when changing the database
 2.0
 - rebuilt for QGIS 3.44: provider connections instead of QSqlDatabase, no more temp connection entries
 - Processing algorithms on a common base, 8 new ones: cluster, simplify, Voronoi, centroids, dissolve, slope / aspect / hillshade, raster to polygons, zonal statistics
 - query editor built on the DB Manager that ships with QGIS, our copy is gone
 - new table registry: browse, inspect, load, export, rename, move, copy, drop, maintenance tools, privileges, comments, CREATE statements, styles, copy to another database, health check with one-click fixes
 - long operations run in the background with progress
 - QGIS projects in the database: open, save, delete
 - database manager: much faster tree, "Last used" button, filter box, server info, sessions and locks, QGIS connection dialog for new connections
 - SQL log of everything the plugin runs
 - raster import: many files at once, compressed tiles, batched inserts, tile size presets
 - imported layers land in their own groups, alpha band for RGBA rasters
 - dialogs redone with native QGIS widgets, dark theme ok, import dialogs remember their settings
 - disconnect button on the toolbar, new scalable icons
 - requires QGIS 3.34.9 or newer
